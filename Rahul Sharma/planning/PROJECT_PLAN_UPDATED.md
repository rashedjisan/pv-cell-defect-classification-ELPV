# Updated Project Plan - Final Implemented Scope

    ## Objective
    Deliver a reproducible binary classifier for **Functional vs Defective** with leakage-aware evaluation, interpretable diagnostics and versioned evidence.

    ## Final work packages
    - data acquisition and audit
- endpoint construction
- frozen stratified split
- preprocessing/augmentation
- logistic/CNN/ResNet18/EfficientNet-B0 training
- validation locking
- locked test/statistics
- calibration/robustness/subgroups/explainability
- final evidence and interface

    ## Deliverables
    - Executed implementation notebook.
    - Saved model artefacts and locked thresholds.
    - Tables/figures supporting the final report.
    - Initial and final architecture/workflow artefacts.
    - Searchable PDF and editable DOCX assessment reports.
    - Repository planning, task-allocation and project-management records.

    ## Scope boundary
    The repository implements a research proof-of-concept. Production deployment and professional decision-making are outside scope.
